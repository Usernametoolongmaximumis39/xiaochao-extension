# 小抄的拓展

面向三国杀 OL 的第三方用户脚本，配合 [小抄](https://xiaochao.org/) 使用。提供小抄通信拦截、更新入口、秒杀连点、盖主速刷、百胜战功面板与心愿进度显示。支持范围以脚本头部的 `@match` 和实际客户端为准。

当前版本：**2.6.7**（2026-11-06）。本版新增心愿武将格数进度，以及心愿武将/皮肤最近一次成功单抽或五连的净增长显示。

## 功能介绍

| 功能 | 脚本会做什么 |
| --- | --- |
| 小抄通信拦截 | 拦截小抄脚本发往 `*.xiaochao.org` 的网络请求和跳转。被拦截的跳转提示可以手动关闭。 |
| 原版小抄更新 | 接管小抄 HUD 的「检测更新」按钮，仍可访问官网检查版本。桌面端打开用户脚本更新页，移动端更新本机缓存，重进游戏后生效。 |
| 秒杀连点 | 在小抄的「秒杀连点」面板中选择商品后，可开启自动购买。购买结果以游戏返回为准。 |
| 盖主速刷 | 在「小抄 → 配置 → 游戏辅助」里分别开启「盖主（小号）」和「反贼（大号）」，自动处理部分开局、选将和下一轮准备操作。「点将（百胜）」提供不点将、随机点将和按序点将三种方式。 |
| 百胜战功 | 查看武将百胜进度和技能战功状态。触屏端点击「百胜战功」会打开拓展面板。 |
| 心愿进度 | 心愿武将显示三位小数的格数（如 `9.327/13`）；武将和皮肤显示最近一次成功单抽或五连的净变化。皮肤沿用百分比，变化以百分比点显示。关闭界面、切换页签或更换心愿后清空本次变化。 |
| 官服 95 折充值 | 官服页面提供微信和支付宝扫码充值入口，按填写的账号、玩家 ID 和元宝数量生成付款码。移动端另提供「打开支付宝付款」按钮。 |
| 移动端内置小抄 | 首次使用时从小抄官网下载安装到本机缓存，后续进游戏自动加载。启动异常时可从自检卡片复制诊断信息。 |

## 桌面浏览器

1. 在 Chrome 或 Edge 中安装支持用户脚本的管理器（如 Tampermonkey），授予它在游戏页运行脚本的权限。
2. 从小抄官网安装原版小抄。在本项目的 Releases 下载 `xiaochao-extension-<版本>.user.js`，用同一管理器导入。也可以在管理器中新建脚本，将仓库根目录的 `小抄的拓展-<版本>.js` 全文粘贴进去并保存。
3. 确认两个脚本都已启用，重新打开游戏页。可以在浏览器控制台搜索 `[BlockXiaochao]` 确认拓展启动。PC 默认使用独立安装的原版小抄。
4. 更新拓展时导入新的 Release 脚本并刷新。小抄 HUD 的更新按钮用于检查原版小抄。

## 官方微端（Windows / macOS）

1. 安装官方三国杀 OL 微端，再按小抄官网说明安装小抄微端插件并成功运行一次。
2. 从 Releases 下载并解压 `xiaochao-micro-client-<版本>.zip`，完全退出微端。
3. Windows 右键 `install.bat` 以管理员身份运行。macOS 在解压目录执行 `sudo bash install.sh`。
4. 重新打开微端。更新拓展时，用新版安装包重新安装。如果小抄微端插件升级后拓展消失，也可重跑安装器。

安装器给本机已安装的小抄微端插件打补丁。恢复脚本会同时移除小抄微端插件并恢复官方微端。自定义路径、恢复步骤及排查方法见 [微端使用说明](微端使用说明.md)。

## 移动端（iPhone / iPad）

1. 在 Safari 启用支持用户脚本的扩展（如 Stay），允许它在游戏页运行。
2. 下载并导入同一个 `xiaochao-extension-<版本>.user.js`。如果之前装了原版小抄或 iPad 页面版，先停用它们，避免重复加载。
3. 打开游戏页，按提示点「下载小抄」。拓展从小抄官网取脚本并保存在本机。下载完成后点「重进游戏」。
4. 小抄 HUD 出现后即可使用。单点 HUD 的更新按钮可检查原版更新，长按约 1.2 秒可切换自动检查。更新拓展本身时，导入新版 Release 脚本。

移动端流程以 iOS / iPadOS Safari 为主。安卓环境的注入兼容性待验证。排查时可在自检卡片点「复制诊断」。页面版备选方法见 [iPad 使用说明](iPad使用说明.md)。

## 源码与构建

仓库提供拓展源码、微端安装器模板及生成工具。需要本地对照原版时，从小抄官网自行下载到 `原版小抄/`，仅作本机只读参考，不提交或随 Release 分发。

```bash
node --check 小抄的拓展-2.6.7.js
node 工具/微端/生成微端安装包.js
```

微端安装包生成在 `工具/微端/输出/`。各版本变更见 [更新日志](更新日志.md)。

2.6.7 心愿模块已按原版小抄 1.6.68 和官方客户端接口核对，发布前用户已确认完成测试。其他功能尚未完成针对 1.6.68 的全量适配验证。各平台的验证范围见更新日志。
